# NHIS End-to-End Customer Churn Analysis

## 📌 Project Overview
This project focuses on analyzing customer behavior and predicting customer churn using the NHIS dataset. The objective is to identify the key factors influencing churn and generate actionable business insights to improve customer retention.

---

## 🎯 Business Objective
Customer churn significantly impacts business growth and profitability. The goal of this project is to:
- Analyze customer characteristics and behavior patterns.
- Identify the factors contributing to customer churn.
- Develop insights that support retention strategies.
- Present findings through data visualization and reporting.

---

## 📊 Dataset Description
The project uses the `INDUSTRY.csv` dataset containing customer-related attributes used for churn analysis.

Key activities performed:
- Data loading and inspection
- Missing value analysis
- Duplicate value analysis
- Data type verification
- Exploratory Data Analysis (EDA)
- Visualization of customer behavior patterns

---

## 🔍 Exploratory Data Analysis (EDA)
The EDA phase included:
- Descriptive statistics
- Distribution analysis
- Univariate analysis
- Correlation analysis
- Outlier detection
- Feature relationship analysis
- Visualization using charts and plots

---

## 🤖 Machine Learning Approach
The project primarily focused on understanding customer behavior through EDA. The analysis provides a foundation for future predictive modeling using classification algorithms such as:
- Logistic Regression
- Decision Tree Classifier
- Random Forest Classifier
- Gradient Boosting Classifier

---

## 💡 Key Findings and Business Insights
- Identified patterns associated with customer churn.
- Highlighted variables that may influence retention.
- Generated visual insights to support business decisions.
- Provided recommendations for reducing churn and improving customer satisfaction.
